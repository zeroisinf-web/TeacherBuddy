# TeacherBuddy — राजस्थान शिक्षक साथी

## पाँच मिनट में शुरू करें

1. `TeacherBuddy.html` ब्राउज़र में खोलें, या होस्ट की हुई वेबसाइट खोलें।
2. **बैकअप व सेटिंग** में विद्यालय, शिक्षक और सत्र लिखकर **सहेजें** दबाएँ।
3. **विद्यार्थी सूची** में नाम जोड़ें। एक साथ कई नाम जोड़ने के लिए हर पंक्ति पर एक नाम लिखें। कक्षा/सेक्शन एक समान रखें, जैसे `3-A`।
4. **दैनिक उपस्थिति**, **आकलन व अंक**, **पोर्टफोलियो** और अन्य टूल उपयोग करें। काम पूरा होने पर **सहेजें** दबाएँ।
5. नियमित रूप से **बैकअप डाउनलोड करें**। यह निजी रिकॉर्ड वाली फ़ाइल है; सुरक्षित रखें।

## रोज़ के काम

- उपस्थिति में खाली का अर्थ दर्ज नहीं; अनुपस्थित होने पर अलग स्थिति चुनें। विद्यालय अवकाश का विकल्प अलग है।
- पोषाहार में पहले उस महीने का प्रारंभिक शेष भरें, फिर वास्तविक प्राप्ति, उपयोग और खर्च। दूध की इकाई लीटर है। शेष ऋणात्मक होने पर प्रविष्टि नहीं सहेजी जाएगी।
- समय-सारणी में शिक्षक, कक्षा या कमरे का समय टकराने पर सुधार का संदेश मिलेगा।
- प्रपत्र और प्रश्न-पत्र संपादित कर सकते हैं। **प्रिंट / PDF** से ब्राउज़र का प्रिंट विकल्प खुलेगा; उसमें **Save as PDF** चुनें। प्रश्न और उत्तर अलग प्रिंट करें।
- **राजस्थान कार्य सहायता** से तैयारी के काम अपनी चुनी तारीख पर काम सूची में जोड़ें। यह सरकारी अंतिम तिथि तय नहीं करता।

## ऑफ़लाइन और डेटा

एकल HTML फ़ाइल के नए टूल बिना इंटरनेट चलते हैं। होस्ट की हुई ऐप को ऑफ़लाइन इस्तेमाल करने से पहले पूरा लोड करें और **बैकअप व सेटिंग** में ऑफ़लाइन प्रति तैयार होने का संदेश देखें। इंस्टॉल करने का विकल्प ब्राउज़र के अनुसार बदलता है।

सरकारी पोर्टल, लाइव परिणाम और बाहरी PDF के लिए इंटरनेट चाहिए। ऐप खुद पोर्टल पर डेटा जमा नहीं करती। ऐप बंद होने पर स्मरण सूचना नहीं आती।

डेटा इसी ब्राउज़र/डिवाइस में रहता है। ब्राउज़र डेटा साफ़ करने से रिकॉर्ड मिट सकते हैं। दूसरे ब्राउज़र, फोन या HTML प्रति में डेटा ले जाने के लिए बैकअप आयात करें। आयात पूरे नए कार्यस्थल के सभी सत्रों का डेटा बदलता है; पहले वर्तमान बैकअप लें। पुराने टूल के पत्र, वेतन विवरण और सहेजे लिंक इस कार्यस्थल बैकअप में शामिल नहीं हैं।

सत्र बदलने से पुराना डेटा नहीं मिटता। पुराने सत्र का नाम फिर भरकर उसे देख सकते हैं। नए सत्र में बच्चे स्वतः अगली कक्षा में नहीं जाते।

## English quick start

Open the HTML file → Backup & settings → set school and session → Student roster → add names → use a tool → Save → download a backup regularly.

The interface supports Hindi and English, labelled icons and larger text. Print through the browser or select Save as PDF. Forms and meal statements are working drafts; verify the current Rajasthan order and prescribed district format before official submission.
